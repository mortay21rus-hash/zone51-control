# Zone51 Control

Нативная утилита для настройки **Zone 51 Garnet** на **macOS с Apple Silicon**: переназначение клавиш, русская ПК-раскладка и управление RGB-подсветкой.

[Скачать приложение](https://github.com/mortay21rus-hash/zone51-control/releases/latest) · [Описание программы](docs/About.ru.md) · [Протокол устройства](docs/Protocol.md) · [Проверки](docs/Verification.md)

## Почему я сделал эту программу

У меня сломалась основная клавиатура, и я подключил к Mac Zone 51 Garnet. Расположение Win и Alt оказалось непривычным, а точка и запятая в русской раскладке macOS не совпадали с обозначениями на клавишах.

Я сделал Zone51 Control, чтобы настроить клавиатуру под себя и управлять подсветкой прямо с Mac. Основой для работы с устройством стала Windows-программа Zone51 Keyboards Beta. Сама утилита написана на Swift и SwiftUI, работает нативно на Apple Silicon и использует системные API Apple.

## Возможности

- **Переназначение клавиш.** Выбор исходной клавиши на схеме Garnet и нового назначения, включая цифровой блок. Готовая замена Win и Alt добавляет два правила одним нажатием.
- **Отдельные настройки Garnet.** Переназначения применяются к выбранной USB-клавиатуре, а не ко всем устройствам Mac.
- **Русская — ПК.** Выбор встроенной раскладки macOS: точка на клавише `/` справа от «Ю», запятая — `Shift + /`.
- **RGB-подсветка.** Выбор эффекта, яркости, скорости и пользовательского цвета в поддерживаемых режимах. Подсветка сохраняется в памяти клавиатуры.
- **Восстановление.** Резервные копии исходной подсветки и назначений клавиш, возврат к сохранённому состоянию и откат при ошибке записи.
- **Работа в фоне.** Значок в строке меню, настройка автозапуска и повторное применение назначений после подключения клавиатуры и выхода Mac из режима сна.

## Поддержка

| Компонент | Поддерживается |
| --- | --- |
| Клавиатура | Zone 51 Garnet |
| Подключение | USB |
| Mac | Apple Silicon, ARM64 |
| Система | macOS 14 и новее |
| Зависимости приложения | Только системные фреймворки Apple |

Citrin, другие клавиатуры с тем же USB ID, Bluetooth, макросы и обновление прошивки не поддерживаются. Fn обрабатывается самой клавиатурой и недоступна для обычного системного переназначения.

Это независимый проект, не связанный с производителем ZONE 51.

## Установка

1. Скачайте ARM64-архив из [Releases](https://github.com/mortay21rus-hash/zone51-control/releases/latest).
2. Распакуйте его и перенесите **Zone51 Control.app** в папку **«Программы»**.
3. В системных настройках откройте **«Конфиденциальность и безопасность → Мониторинг ввода»** и разрешите доступ для Zone51 Control.
4. Перезапустите приложение после выдачи разрешения.

Сборка имеет локальную ad hoc подпись. Developer ID и нотарификация Apple в этом выпуске отсутствуют. Также доступна самостоятельная сборка из исходников.

Приложение использует разрешение для доступа к HID-устройству. Обработчики глобального ввода не регистрируются, нажатия не записываются. Текст в поле проверки ввода не сохраняется. Сетевых функций, учётной записи и аналитики в приложении нет.

## Использование

### Клавиши

Выберите клавишу на схеме, укажите новое назначение и нажмите **«Добавить назначение»**. Для сохранения изменений нажмите **«Применить назначения»**. Кнопка **«Поменять Win и Alt»** подготавливает готовую пару правил. Неприменённые изменения отмечаются отдельно.

**«Восстановить исходные назначения»** возвращает настройки, сохранённые до первого изменения в приложении. Исходные назначения сохраняются отдельно для каждого USB-порта.

### Раскладка

В разделе **«Раскладка»** выберите **«Русская — ПК»**. Раскладка действует во всех приложениях и для всех подключённых клавиатур. Обычная русская и английская раскладки остаются доступны.

### Подсветка

Выберите эффект и параметры, затем нажмите **«Применить подсветку»**. Ползунки и выбор цвета не записывают изменения автоматически.

Для пользовательского цвета выберите, например, **«Постоянный свет»** или **«Дыхание»** и отключите **«Многоцветный режим»**. Некоторые эффекты используют встроенную палитру — это указано в интерфейсе.

**«Восстановить исходную подсветку»** возвращает состояние до первого изменения в приложении. Папка резервных копий открывается из раздела **«Приложение»**.

### Работа в фоне

Окно можно закрыть: приложение продолжит работать в строке меню. Чтобы назначения восстанавливались после переподключения и пробуждения Mac, процесс приложения должен оставаться запущенным. Автозапуск включается в разделе **«Приложение»**.

До входа в учётную запись, включая экран FileVault, действуют исходные клавиши.

## Сборка

Требуется Xcode с поддержкой Swift 6.

```bash
git clone https://github.com/mortay21rus-hash/zone51-control.git
cd zone51-control
swift test
./scripts/build.sh ./dist
```

Готовое приложение появится в `dist/Zone51 Control.app`. Скрипт собирает ARM64-версию, добавляет ресурсы и иконку, подписывает приложение локальной подписью и проверяет её.

## Диагностика

Внутри приложения находится `Contents/MacOS/zone51-tool`.

| Команда | Назначение |
| --- | --- |
| `diagnose` | Чтение устройства, подсветки, назначений и выбранной раскладки |
| `verify-hardware` | Временное изменение цвета и яркости с восстановлением состояния до проверки |
| `verify-mapping` | Применение и проверка замены Win/Alt с последующим восстановлением |
| `setup-mac` | Применение замены Win/Alt и выбор «Русская — ПК» |
| `restore-lighting` | Восстановление исходной подсветки из резервной копии |

Команды `verify-hardware`, `verify-mapping`, `setup-mac` и `restore-lighting` изменяют настройки. Проверки используют отдельные временные резервные копии.

## Проверки и ограничения

В проекте 20 автоматических тестов: проверка протокола и ответов устройства, сохранения резервных копий, отката после ошибки записи, назначений клавиш и символов русской ПК-раскладки.

На физической Garnet проверены чтение настроек, запись цвета и яркости, подтверждение записанных значений и восстановление исходных данных. Применение назначений подтверждено чтением системной таблицы macOS. Работа с подсветкой также проверена через установленное приложение.

Физическое нажатие каждой клавиши, все эффекты подсветки, автозапуск, сон и перезагрузка отдельно не проверялись. Подробнее — в [отчёте о проверках](docs/Verification.md).
